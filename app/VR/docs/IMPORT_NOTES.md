# Import notes

This repository was created on September 8, 2026 after the working prototype had already been built and tested locally. The Akeil branch imports that implementation. Its commits organize the existing work into reviewable stages; they are not a claim that the original development occurred in this Git history.

Source comments explain coordinate-system ownership, local component animation, asynchronous map-save isolation, and restoration of the original pose. The build journal records the sequence of decisions, corrections and evidence. Future changes should append dated entries with what changed, why, verification and remaining gaps.

No OpenAI key, bridge credential, private tunnel configuration, device identifier, source photograph, captured camera frame, or saved room map is included. The pairing configuration must be generated locally. The retained signing-team setting belongs to the original build; replace it with your Apple development team when building elsewhere.
