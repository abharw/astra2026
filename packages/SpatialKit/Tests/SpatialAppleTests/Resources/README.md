# Native detail fixtures

These tiny USDZ packages are repository-owned synthetic geometry, generated by `scripts/check-asset-group-compiler.py`. They depict the same desk lamp with a base, nested stem assembly and shade; no third-party rack CAD is included.

`lamp-overview.usdz` comes from `runtime/export-fixture/desk-lamp-unindexed.usdz`; the native test registers its whole hierarchy as one opaque part. `lamp-detail.usdz` comes from `runtime/export-fixture/desk-lamp.usdz`; the test registers its three authored part roots separately. Distinct package hashes exercise a real deferred decode without requiring Blender or network access when running Swift tests.

The tests use authored rest poses, then move/rotate the selected instance before expansion. They verify preservation of its pose, another instance's native entity identity, child edits, Undo, digest failure and cancellation during asynchronous preparation. This proves the generic scene path independently of the server-rack example.

`lamp-detail-alternate.usdz` is the identical detail package with a ZIP comment (`Distinct native cache fixture`). It preserves all aligned members while giving the package a third content hash, to test a candidate that needs both an unused cached resource and a newly loaded resource.
