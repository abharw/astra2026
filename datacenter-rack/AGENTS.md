# Rack Lab agent entry point

For opening the rack, answering equipment questions, loading/unloading saved detail, editing equipment, or integrating the library into another runtime, read [docs/AGENT_USAGE.md](docs/AGENT_USAGE.md) before operating it.

Use `models/lazy/rack-exterior.blend` as the default. Load saved detail by the manifest asset ID and a real selected server ID. Preserve source metadata and its evidence level through edits and exports.

For rebuilding geometry or changing sources, read [docs/REPRODUCING.md](docs/REPRODUCING.md). For hardware identity and claim boundaries, read [docs/COMPONENT_GUIDE.md](docs/COMPONENT_GUIDE.md). For production history and verification, read [docs/HACKATHON_PROCESS.md](docs/HACKATHON_PROCESS.md) and [docs/VERIFICATION.md](docs/VERIFICATION.md).
