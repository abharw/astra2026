# Product

## Register

Product UI: a native iPhone and iPad spatial learning app. The camera and interactive assembly are the main surface; conversation controls serve that activity.

## Users and purpose

People exploring hardware architecture ask Astra questions, point at components, and request changes to a spatial assembly. The first example is a server rack. A useful result teaches how a selected system works while preserving the context of the surrounding assembly.

## Interaction principles

- One conversation accepts typed text and explicit microphone input.
- Connect automatically using the configured service; recover from failures beside the composer and preserve unsent text.
- Detect a hand automatically while the AR view is active. Pointing supplements touch and speech; it is not a setup mode.
- Reveal the level needed by the question. Moving server units preserves their internal assembly; discussing a selected unit can expose specific systems.
- Label activity from actual execution events. Animation must not invent progress or imply an unconfirmed installation.
- Keep reference geometry, reconstructed detail, and generated illustrations distinguishable in context and explanations.

## Visual reference

Arav supplied the ChatGPT iPhone composer as the reference: quiet dark controls, familiar system typography, one rounded prompt field with an embedded microphone, and a clear send action. Keep scene selection contextual and put diagnostic/settings detail in a secondary view.

## Avoid

Persistent developer labels, uppercase branding, redundant connection status, manual Hand On/Off, and permanent Stop/Undo controls. Do not replace the AR scene with a marketing home screen or a dashboard.

## Accessibility and environment

Respect Dynamic Type, VoiceOver, Reduce Motion, keyboard safe areas, and native touch target sizes. Controls need reliable contrast over changing camera imagery. Verify both phone and tablet layouts; Simulator evidence does not establish physical camera or gesture performance.
